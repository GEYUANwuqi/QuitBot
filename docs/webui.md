# 控制台使用说明

控制台通过同源 WebSocket 连接后端，提供概览、账号连接、账号设置、其他设置、接口调试和实时事件。启动方式见 [README](../README.md#快速开始)。

## 登录

首次进入显示登录页。输入终端生成的临时密码后，必须设置新密码才能进入控制台。单次登录默认有效 4 小时，可在「其他设置 → WebUI 与登录」修改。

时长修改对后续新登录生效，当前会话保留原到期时间。刷新页面不续期；到期后返回登录页。右上角提供改密与退出登录，改密会撤销全部已有会话。密码输入不持久化，会话凭证与到期时间仅保存在当前标签页的 `sessionStorage`。

## 概览

概览只展示当前业务账号的连接、绑定、监听状态，以及配置会话和最近调用。状态自动更新；绑定与监听操作集中在「账号设置」。

## 账号连接

1. 在后端所在的图形会话中登录 QQ，并打开主窗口。
2. 进入「账号连接」，页面主动探查一次；打开或切换 QQ 后，可点击「刷新探查」。
3. 卡片只显示进程名、进程 ID 和窗口句柄。点击「连接账号」后，才读取所选窗口的 QQ 号、昵称和头像；读取失败时显示具体原因，可重新连接。
4. 资料完整后保存账号与窗口，保留已有监听与网络配置，并在绑定时核验 QQ 号。成功后进入账号设置，自动选中刚连接的 QQ；首次连接需先配置监听范围。

后端启动及进入其他页面不触发扫描，读取缓存也不会扫描。进入账号连接页的扫描与手动扫描均合并正在进行的探查，仅枚举当前图形会话中的进程窗口信息。连接时会短暂打开所选账号的本人资料卡，头像从无障碍接口定位的头像控件区域读取；其他进程的账号资料保持不动。

使用 Anode 时，QQ 和后端放在同一子会话。界面显示后端 Windows 会话 ID 和最近探查时间。

「断开控制台」只关闭当前浏览器的账号连接。账号设置中的「解除绑定」和「停止监听」分别控制所选账号的 QQ 绑定与监听；页面刷新或退出登录后，已经运行的监听继续工作。

## 账号设置

左侧列表只显示资料完整且已激活的账号，包含连接时读取的头像、昵称和 QQ 号。选择账号后，右侧显示对应运行状态与配置：

- 运行控制：绑定 / 解除绑定、启动 / 停止监听、刷新运行状态。操作始终发送给左侧选中的账号。
- 显示名称、绑定窗口、监听方式与轮询间隔。
- 监听范围：点击「探查会话」，勾选 QQ 已加载的最近会话，再「核验并添加」。也可「手动添加」群号或 QQ 号及对应名称。
- 启动时自动绑定、请求通知观察、群成员变化观察。
- 独立的 HTTP、正向 WebSocket、反向 WebSocket 设置。

资料在连接成功后缓存在内存中，普通刷新复用缓存；刷新发现窗口消失或所属进程变化时，该账号从激活列表隐藏，已有配置保留。在 QQ 中切换账号后，重新连接以更新资料。账号列表切换改变配置和运行控制的对象；概览、接口调试与实时事件所用的业务账号在「账号连接」中切换。

监听范围保存后，在当前账号的「运行状态」中点击「启动监听」。范围为空、QQ 未绑定或该账号有未保存修改时，启动按钮禁用并显示对应提示；正在运行的监听仍可直接停止。运行状态自动更新，刷新状态保留配置草稿。移除会话只修改配置；移除最后一个会话并保存后停止监听。

会话探查针对左侧所选账号，先只读取已加载列表及主窗口当前会话的名称。勾选后通过 QQ 的「复制群号／复制 QQ 号」菜单读取号码和类型，会更新当前图形会话的剪贴板；目标行不在当前加载区域时，会自动滚动定位。探查结果支持名称筛选与手动刷新；没有出现在列表中的会话，先在 QQ 中打开再刷新。同名会话需先设置唯一名称；系统会话若没有号码菜单，可保留为未添加状态。部分会话核验失败时，已成功的会话保留在配置草稿中，失败项逐条显示原因。

默认监听方式为「独立聊天窗口」，每个会话使用单独窗口。启动后先显示「启动中」，所有监听源完成初始化后显示「监听中」。启动或轮询失败会立即显示错误；独立窗口初始化错误包含会话名称、号码和失败步骤。

## 网络连接

在账号设置中点击「添加连接」，弹出的卡片提供三种方式：

| 方式 | 参数 | 用途 |
| --- | --- | --- |
| HTTP | 启用开关、监听地址、端口 | 应用通过 `/api/{action}` 调用接口，提供 Swagger 与 OpenAPI |
| 正向 WebSocket | 启用开关、监听地址、端口 | 应用连接 `/ws`，调用接口并接收事件 |
| 反向 WebSocket | 启用开关、接收地址、接收端令牌、传输内容、重连间隔 | 后端主动连接应用 |

选择卡片后填写参数，点击「确认配置」，再点击页面上的「保存并应用」。已启用连接显示在右侧，点击卡片可以重新编辑或关闭。关闭后保留参数，便于再次启用。

HTTP 与正向 WS 的地址可填写本机 IP、主机名或通配地址，端口独立配置。同一账号填写相同地址与端口时共用监听端点。反向地址使用 `ws://` 或 `wss://`，可选择接口与事件、仅接口或仅事件。

控制台通过同源 `/accounts/{account_id}/ws` 操作账号，关闭对外连接后仍可继续使用。新连接的账号默认不开启对外监听端口。配置保存只重建受影响账号，其他账号保持运行。

配置更新后，后端恢复原有绑定及正在启动或运行的监听；控制台收到服务更新通知后自动恢复账号连接，保留当前页面、调用记录和事件列表。恢复过程中只重新认证与读取状态，业务操作不重发。恢复失败会显示原因。

## 其他设置

| 分类 | 内容 | 生效方式 |
| --- | --- | --- |
| WebUI 与登录 | WebUI 监听地址、端口，单次登录有效期，密码错误次数与暂停登录时长，改密入口 | WebUI 地址和端口重启生效；登录设置热更新，新时长用于新登录 |
| 高级配置 | 完整 JSON，维护 `targets`、`member_bindings`、浏览器来源等细项 | 校验后按字段生效 |

表单与高级配置同步，账号列表及两个设置页面之间切换保留编辑内容。离开设置进入其他功能页前先保存。版本冲突与应用错误直接显示在页面，WebUI 监听变化会提示等待重启。

监听 `0.0.0.0` 或 `::` 时，使用电脑的实际 IP 访问控制台。配置字段与热更新行为见[配置与运行](configuration.md)。

## 接口调试

消息、群文件、公告等业务通过接口调用，完整范围见[能力矩阵](capabilities.md)。动作目录与类型定义由账号 WS 的 `x_get_api_catalog` 提供。

- 支持按分类、动作名和说明检索，表单展示必填字段、枚举和布尔值。
- 对象与数组可通过 JSON 填写；可选参数通过「传入」启用。下拉框支持方向键、Enter 与 Escape。
- 会话参数按接口类型填入当前账号的默认会话标识，提交前可在表单中修改。
- 写操作展示动作名和参数，确认后提交。超时或断线后先查询实际结果，再决定是否重试。
- 响应展示返回值、成功状态与耗时。调用记录最多保留 50 条，选择记录会填入参数，需手动提交。
- 「接口类型」展示输入与返回值。启用 HTTP 后，页脚提供该账号的 Swagger 链接。

发送、上传与下载使用后端电脑上的文件路径，操作范围以接口契约为准。

## 实时事件

可筛选消息、通知、请求、元事件与 QuitBot 扩展事件，支持搜索和原始 JSON 展开。页面最多保留 200 条事件；暂停展示冻结页面快照，事件仍继续接收。恢复展示时显示当前缓冲，清空只影响本页。

群消息的发送人 QQ 号尚未解析时，消息出现在「扩展事件」中，保留发送人名称和正文。需要标准群消息事件时，可在高级配置中为对应账号开启 `resolve_members`，或维护 `member_bindings`；自动解析会增加启动时和监听期间的资料读取操作。

切换业务账号会清空页面回执与事件。断线期间事件不补发，事件范围见 [OneBot 适配](onebot11.md#消息通知与请求事件)。

## 界面设置

右上角切换浅色与深色主题，主题保存在浏览器 `localStorage`。窄屏使用左上角按钮展开导航，账号列表在窄屏横向排列。页面支持 hash 路由及浏览器前进、后退。
